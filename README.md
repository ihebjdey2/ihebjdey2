## Featured Engineering Projects

### AgriDiagnose AI

**Plant-health decision-support platform combining machine learning and software engineering.**

![Python](https://img.shields.io/badge/Python-3776AB?style=flat-square&logo=python&logoColor=white)
![Flask](https://img.shields.io/badge/Flask-000000?style=flat-square&logo=flask&logoColor=white)
![TensorFlow](https://img.shields.io/badge/TensorFlow-FF6F00?style=flat-square&logo=tensorflow&logoColor=white)
![PostgreSQL](https://img.shields.io/badge/PostgreSQL-4169E1?style=flat-square&logo=postgresql&logoColor=white)
![CI](https://img.shields.io/badge/CI-GitHub_Actions-2088FF?style=flat-square&logo=githubactions&logoColor=white)

Built around a frozen **MobileNetV2 39-class model** and a production-oriented Flask application architecture.

- Dataset V2 with **73,563 audited images**
- **39 output classes** across 14 crops
- **95.44% internal test accuracy**
- **95.92% Macro-F1**
- External PlantDoc evaluation used to measure domain shift
- Authentication and prediction history
- REST API and dashboards
- PostgreSQL persistence and database migrations
- Automated tests and CI
- English, French and Arabic UI with RTL support
- Model integrity verification and reproducible evaluation

[View Project](https://github.com/ihebjdey2/ai-plant-disease-detection)
